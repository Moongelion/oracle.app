# Oracle

A minimalist web application for random dice rolls and Tarot card draws.

## Features

### Dice

* d4
* d6
* d8
* d10
* d12
* d20
* d100
* Random dice rolls
* Animated rolling effect
* Multiple dice selection

### Tarot

* Full 78-card Tarot deck
* Major Arcana
* Minor Arcana
* Random card draws

## Technologies

* HTML5
* CSS3
* JavaScript
